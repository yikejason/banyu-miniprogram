# 伴语星球 产品文档

---

## 1. 产品概述

**伴语星球**是一款面向个人的情绪记录与私密表达产品。

它把难以说清的情绪，转成可感知的视觉符号；把日记留在本机、加密保存；在需要被理解时，只把当下的性情与状态，通过专属链接交给你指定的那个人。

产品主张很简单：

- **看见自己**：情绪不再只是文字，而是星球上可辨认的形象。
- **守住自己**：成长轨迹只存在于你的设备里，不进云端。
- **选择被看见**：分享是主动、定向、可收回的，而不是公开动态。

## 3. 目标用户

### 3.1 核心用户

- 习惯用文字消化情绪，但常觉得「说不清自己到底是什么感觉」的人。
- 需要私密记录空间，对云端存储、平台可见性高度敏感的人。
- 希望被特定对象理解（伴侣、家人、密友），但不想把情绪暴露给所有人的人。

### 3.2 使用动机

| 动机 | 用户内心需求 |
| --- | --- |
| 自我觉察 | 把模糊情绪变成可回顾的视觉记忆 |
| 安全感 | 日记只在本地，不被平台、算法、陌生人看见 |
| 被理解 | 把此刻的性情与状态，准确交给那一个人 |
| 成长见证 | 长期回看自己的变化，而不是刷公开动态 |

### 3.3 明确不服务

- 不追求公开曝光、粉丝互动、内容传播。
- 不把情绪作为社交货币。
- 不替代专业心理治疗。

---

## 4. 核心价值主张

1. **情绪可被看见**  
   抽象感受被转译成生动的视觉符号，降低「我不知道怎么形容」的门槛。

2. **记录绝对私密**  
   日记 100% 本地加密保存，不云端存储，成长只属于使用者本人。

3. **分享完全主动**  
   分享链接由使用者生成并亲自发给特定对象；被分享者只能看到分享者授权的性情与状态。

## 5. 功能说明

### 5.1 情绪具象化：把感受变成星球上的视觉符号

#### 功能目标

将难以命名的情绪，转译为可感知、可记忆、可回顾的视觉符号，帮助用户「看见」自己当下的内在状态。

#### 功能描述

- 用户可以用文字、关键词、简单描述或情绪选择，表达当下感受。
- 系统将情绪映射为一套「星球视觉语言」，例如色彩、天气、光晕、星体形态、陪伴物等符号。
- 每一次记录，都会在个人星球上留下对应的视觉痕迹，而不是一条冷冰冰的标签。
- 同一类情绪在不同强度、不同语境下，可以呈现不同层次的视觉变化，避免「开心 / 难过」过于扁平。

#### 用户可完成的事情

- 快速捕捉当下情绪，无需先写完整日记。
- 通过视觉符号确认：「原来我现在是这种感觉」。
- 在星球视图中回看某一天、某一段时期的情绪面貌。
- 以图像化方式理解自己的情绪节奏，而不是只翻文字列表。

#### 体验原则

- 视觉符号应生动、克制、有温度，避免过度娱乐化或恐吓感。
- 情绪表达以用户主观感受为准，不进行诊断式判定。
- 允许「说不清」：模糊、混杂、说不出口的状态也应有对应符号。

---

### 5.2 个人私密日记：本地加密，记录成长

#### 功能目标

提供一个真正私密的个人日记空间，用于持续记录情绪、事件与自我变化；所有内容仅保存在用户本机，并全程加密。

#### 功能描述

- 支持撰写私密日记：可与当日情绪符号关联，也可独立书写。
- **所有日记内容 100% 本地加密保存，不上传云端，不做云同步。**
- 本地数据使用加密存储；离开本机环境后，他人无法直接读取明文。
- 提供按时间、情绪、主题回看的能力，帮助用户看见自己的成长轨迹。
- 支持长期留存：记录的是「我如何走过这些日子」，而不是一次性发泄。

#### 隐私边界（必须遵守）

| 规则 | 说明 |
| --- | --- |
| 不云端保存 | 日记正文、附件、情绪原始记录均不上传服务器 |
| 本地加密 | 设备本地以加密形式存储，明文不落未保护区域 |
| 无平台可见性 | 日记默认对任何其他用户、运营方、推荐系统不可见 |
| 无后台阅读 | 产品不因推荐、审核、运营分析读取日记明文 |

#### 用户可完成的事情

- 写下不想被任何人看见的内容。
- 把情绪符号与日记对照，看见「那天我看起来怎样，实际写了什么」。
- 回顾一周、一月、一年的记录，识别自己的变化与反复。
- 在更换使用习惯时，仍能把成长轨迹留在自己手里。

#### 体验原则

- 打开日记应有「这是只属于我的房间」的感受。
- 不诱导公开、不设置默认分享、不插入社交互动。
- 本地加密是产品承诺，不是可选项。

---

### 5.3 私密分享定制：只让想看见的人看见

#### 功能目标

让用户把「此刻的性情与状态」主动交给特定对象，而不是发布到公共空间。分享必须定向、可控、可结束。

#### 功能描述

- 用户可从当前情绪 / 状态中，定制一份「可被他人看见」的分享内容。
- 分享不是公开动态，而是生成**专属分享链接**。
- 链接由用户**主动发送**给特定对象（如微信、短信、面对面出示等），产品不代为广播。
- 被分享者打开链接后，能够看到分享者授权展示的：
  - **性情**：较稳定的气质、性格底色、表达风格；
  - **状态**：此刻或近一段时间的情绪面貌与状态表现。
- 未获得链接的人，无法看到任何分享内容。
- 用户可随时停止分享、失效链接，或更换一份新的分享。

#### 分享内容范围

被分享者默认看到的是「分享者愿意被理解的那一面」，而不是完整日记。

| 可见 | 默认不可见 |
| --- | --- |
| 用户选择公开的性情画像 | 私密日记正文 |
| 用户选择公开的当前 / 近期状态 | 未授权的历史情绪细节 |
| 对应的视觉符号与简要状态说明 | 本地加密存储的全部记录 |

#### 用户可完成的事情

- 决定「这次让谁看见、看见什么」。
- 把链接只发给伴侣、家人或一位朋友。
- 让对方理解自己现在的性情和状态，而不必公开解释全部故事。
- 分享结束后收回可见权，星球重新只属于自己。

#### 体验原则

- 分享必须是用户主动发起，系统不得自动推送给通讯录或好友。
- 「能被谁看见」始终由用户决定。
- 被分享者是受邀理解的人，不是围观的人。
- 分享链路与日记本地加密原则一致：分享内容最小化、授权明确、可撤销。

## 6. 关键用户场景

### 场景 A：晚上说不清自己是什么心情

用户打开伴语星球，用很短的话或一个模糊感觉留下记录。星球上出现对应的视觉符号。她第一次觉得：原来今天不是「累」，更像是被抽空后又强撑着发光。

### 场景 B：把真正的话只写给自己

用户写下一篇不想给任何人看的日记。内容加密保存在本机，不进云端。过了三个月回看，她看见自己从反复自我怀疑，慢慢变成能够点名那种情绪。

### 场景 C：只想被一个人理解

用户今天很难过，但不想发朋友圈。她定制了一份分享，把链接发给伴侣。伴侣打开后看到她的性情底色和此刻状态，于是知道该如何靠近，而不是猜。

### 场景 D：分享结束，世界重新关上

用户结束这段需要被看见的时刻，关闭分享链接。星球回到只属于自己的状态，日记依然只在本地。

## 8. 隐私与安全原则

伴语星球以「私密」为产品底座，而不是附加功能。

1. **日记本地化**  
   个人日记及完整情绪记录保存在用户设备，100% 本地加密，不云端保存。

2. **默认不可见**  
   任何内容在用户明确分享前，对他人不可见。

3. **分享最小化**  
   分享只包含用户勾选的性情与状态，不默认附带日记原文。

4. **链接定向**  
   分享链接由用户主动发给特定对象，产品不提供公开广场、推荐流或陌生人浏览。

5. **可撤回**  
   用户可随时让链接失效，被分享者不再能查看。

6. **不分析用户内心**  
   不为广告、社交推荐或内容审核读取日记明文。

## 9. 设计原则

- **克制**：少按钮、少打断，不制造社交焦虑。
- **温柔**：视觉与文案陪伴情绪，不评判、不诊断。
- **具体**：用符号把抽象感受变具体，而不是用空泛鸡汤。
- **主权在用户**：记什么、谁能看、看多久，都由用户决定。
- **私密优先**：任何新功能若削弱本地加密或定向分享，则不予采用。

---

## 10. 成功标准

产品是否成立，不看公开传播量，而看这三件事是否成立：

1. 用户能通过视觉符号认出自己的情绪。
2. 用户愿意把真正私密的话写进本地日记，并相信它不会离开这台设备。
3. 用户愿意把链接只发给在意的人，且对方能理解分享者的性情与状态。

辅助观察（不作为社交指标）：

- 用户是否持续回看自己的星球与日记。
- 分享是否保持「少数人、强关系、短时需要」的形态。
- 用户是否清楚知道：日记不上云，分享可撤回。
